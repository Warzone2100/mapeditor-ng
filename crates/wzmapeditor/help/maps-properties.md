# Map Properties

Open the Map Properties dialog with `Map > Properties…`. The dialog shows read-only information about the current map (size and tileset) alongside editable metadata fields.

## Fields

- **Name** — the map's display name shown in the game lobby and maps database. Must be unique among maps with the same player count if you plan to publish.
- **Players** — number of players the map is designed for. The dropdown offers 1 to 8 and 10. This determines which maps-database bucket the map is filed under.
- **Author** — your name or handle as the primary author.
- **Additional authors** — comma-separated list of any co-authors or original creators whose work is included.
- **License** — an SPDX license identifier governing redistribution. Defaults to `CC0-1.0` (public domain dedication), which is the most permissive and recommended for community maps.

Click `OK` to apply changes. Changes take effect immediately and mark the map as modified (unsaved).
