# Validation & Problems

The **Problems** panel continuously checks the open map against a set of rules and lists every issue it finds. Fixing problems before publishing prevents maps from crashing or behaving incorrectly in-game.

## Navigating to Issues

Issues are grouped by category under collapsible headers. Double-click any issue that has a map location to move the viewport camera to that spot and, where possible, select the offending object automatically. A tooltip on the issue row confirms whether double-clicking will navigate.

## Disabling a Warning Rule

Right-click any warning to get a context menu with a **Disable** option for that rule. The rule is saved to your configuration and suppressed from future runs. To re-enable rules, go to **Settings > Problems** where every available rule can be toggled on or off.
